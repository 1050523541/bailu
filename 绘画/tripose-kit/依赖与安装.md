# 依赖与安装（中文）

套件显示名：**TriPose-SDXL-Anima-Krea2-Wan22 I2V图+视频工作流**（v1.6.1）

按顺序做完后必须 **重启 ComfyUI**，再确认节点搜索里能找到 `UltralyticsDetectorProvider` 与 `TriPoseZhTagMap`（显示名：TriPose 中文短标签映射）。

默认 Comfy 根目录示例：`E:\AIGC\ComfyUI-aki-v3\ComfyUI`（下称 `ComfyUI/`）。

## 〇、工作流一览（装完共用底座后再按需补模型）

| 工作流文件 | 用途 | 额外模型 |
|------------|------|----------|
| `CF-TriPose-SDXL-template.json` | SDXL **三态立绘** | 全量 SDXL/Illustrious/NoobAI checkpoint |
| `CF-TriPose-SDXL-single.json` | SDXL **单图** | 同上 |
| `CF-TriPose-Anima-single.json` | Anima **单图** | UNET + Qwen CLIP + Qwen VAE（+可选 LoRA） |
| `CF-TriPose-Krea2-single.json` | Krea2 **单图** | UNET + **krea2** CLIP + Qwen VAE（+可选 LoRA） |
| `CF-Wan22-I2V-single-frame.json` | Wan2.2 **I2V** | Hi/Lo UNET + UMT5 + wan_2.1_vae |

布局以套件内 JSON 为准（已与本机用户定稿对齐）。**不要**用旧模板坐标覆盖用户拖好的布局。

## 一、环境前提

- 已安装可用的 ComfyUI（建议 ≥ 0.28 / 前端能加载 `CreateVideo`/`SaveVideo`）
- 显存建议：
  - SDXL 三态：≥ 12GB（896×1280 三路 + FaceDetailer）
  - Anima / Krea2 单图：≥ 12–16GB（默认约 896×1152）
  - Wan I2V：≥ 16GB（默认 480×832 · 49 帧）
- 网络可访问 GitHub / Hugging Face（或使用 `hf-mirror.com`）
- 使用 rgthree **Power Lora / Seed** 时，建议关闭 Nodes 2.0：`Comfy.VueNodes.Enabled = false`，然后刷新 UI

## 四、按工作流：模型与验收

### A. `CF-TriPose-SDXL-template` / `CF-TriPose-SDXL-single`

| 类型 | 路径 | 说明 |
|------|------|------|
| Checkpoint | `models/checkpoints/*.safetensors` | **全量** ckpt（约 6GB+）；不要塞 UNET-only |
| VAE | （一般内嵌） | 通常无需外置 |

推荐目录见 [`profiles/checkpoints.catalog.md`](profiles/checkpoints.catalog.md)。  
模板默认示例名可换：`oneObsession_v23` / 单图示例 `cocoStyleNoobaiXL_v70` 等。

**验收**

1. 打开对应工作流；Checkpoint 下拉能看到全量 ckpt  
2. Seed 为 `-1`（Randomize Each Time）  
3. 三态：只开「开·图1」→ 只出 `CF_TriPose_01_normal`；三路全开 → 同 seed 三张  
4. 单图：Queue 出 `CF_TriPose_single_*.png`  
5. 映射节点词典为 `danbooru_zh+nsfw`

---

### B. `CF-TriPose-Anima-single`

| 类型 | 默认文件名 | 放置路径 |
|------|------------|----------|
| UNET | `miaomiao3DHarem_animaLH3D10.safetensors`（可切 `miaomiaoHarem_anima15`） | `models/diffusion_models/` |
| CLIP | `qwen_3_06b_base.safetensors` | `models/text_encoders/` |
| VAE | `qwen_image_vae.safetensors` | `models/vae/` |
| LoRA（可选，默认关） | `Anima_AI_Cunnyfunky.safetensors` 等 | `models/loras/` |

CLIP 节点 type 用 Anima 管线默认（工作流内为 `stable_diffusion` 槽位加载 Qwen 权重）；**不要**把 Anima UNET 塞进 SDXL Checkpoint 加载器。

Qwen Image 常用拆分包入口（Comfy-Org）：在 Hugging Face 搜 `Comfy-Org` + `Qwen-Image` / 对应 text_encoders · vae 目录。

**采样默认**：30 steps · CFG 4.5 · `er_sde`/`simple`；Turbo 时可改 12 steps · CFG 1。

**验收**

1. UNET / CLIP / VAE 下拉均有上述文件  
2. Queue 出 `Anima_MiaoMiao_single_*.png`  
3. 无 CLIP shape / missing model 红错

---

### C. `CF-TriPose-Krea2-single`

| 类型 | 默认文件名 | 放置路径 |
|------|------------|----------|
| UNET | `moodyKrea2Mix_cutieXEDITION.safetensors` | `models/diffusion_models/` |
| CLIP（**必须 krea2**） | `qwen3vl_4b_fp8_scaled.safetensors` | `models/text_encoders/` |
| VAE | `qwen_image_vae.safetensors` | `models/vae/` |
| LoRA（可选） | `Niji_Sweet_Spot-KREA2_v1.safetensors`、`lora_krea2_nd_dark.safetensors` 等 | `models/loras/` |

**CLIP 直链（必下，勿用 Anima 的 `qwen_3_06b_base` 顶替）**

- HF：https://huggingface.co/Comfy-Org/Krea-2/resolve/main/text_encoders/qwen3vl_4b_fp8_scaled.safetensors  
- 镜像：https://hf-mirror.com/Comfy-Org/Krea-2/resolve/main/text_encoders/qwen3vl_4b_fp8_scaled.safetensors  

CLIPLoader **type = `krea2`**。文件不完整会报类似 `shape '[2560, 4096]' is invalid` —— 删掉坏文件重新下完整权重。

**采样默认**：8 steps · CFG 1 · `er_sde`/`simple`；精炼 4 steps · denoise 0.3。

**验收**

1. CLIP 文件体积正常（完整 TE，非几 MB 残片）  
2. Queue 出 `Krea2_MoodyCutie_single_*.png`  
3. Seed 保持 `-1`

### D. `CF-Wan22-I2V-single-frame`

| 类型 | 默认文件名 | 放置路径 |
|------|------------|----------|
| UNET Hi | `DasiwaWAN22I2V14BLightspeed_snatchkissHighV11.safetensors` | `models/diffusion_models/` |
| UNET Lo | `DasiwaWAN22I2V14BLightspeed_snatchkissLowV11.safetensors` | `models/diffusion_models/` |
| CLIP | `umt5_xxl_fp8_e4m3fn_scaled.safetensors`（type=`wan`） | `models/text_encoders/` |
| VAE | `wan_2.1_vae.safetensors` | `models/vae/` |

- Low 直链（pruned ≈ 13.53GB）：https://civitai.com/api/download/models/2953485  
- High 与 Low 同模型页成对下载  
- UMT5 / VAE：Comfy-Org `Wan_2.1_ComfyUI_repackaged` / `Wan_2.2` 拆分包（`split_files/text_encoders` · `split_files/vae`）  
- Lightspeed = Lightning 已烘焙 → **不要**再叠 lightx2v LoRA  

**默认**：4 steps · CFG 1 · shift 5 · 480×832 · 49 帧 · 16 fps ≈ 3s（16GB 友好）。

**验收**

1. Hi/Lo/UMT5/VAE 四个下拉均有文件  
2. 换「起始图像」后 Queue，输出 `video/Wan22_SnatchKiss_I2V*.mp4`（或 SaveVideo 前缀对应路径）  
3. 原生 `CreateVideo` / `SaveVideo` 节点可用（缺则升级 Comfy）
