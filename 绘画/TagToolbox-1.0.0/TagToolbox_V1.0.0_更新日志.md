# TagToolbox 词库工具箱 V1.0.0 更新日志

本次更新把词库工具箱正式封装成可双击运行的桌面程序，并补齐提示词预设管理、分类着色和配图本地保存。玩家现在可以在自带窗口里完成词库组合、分类编辑与预设存取，不再依赖另外打开浏览器页面。

## 新功能

### 桌面程序

- 新增桌面程序包 **`TagToolbox-1.0.0`**，双击 **`TagToolbox-1.0.0.exe`** 即可启动。
- 程序使用系统内嵌窗口显示界面；关闭窗口即退出，不再额外弹出 Chrome / Edge 标签页。
- 窗口标题会显示版本号，例如 **「TagToolbox 词库工具箱 v1.0.0」**。

### 双模式工作台

- 顶部提供 **「词库组合」** 与 **「分类编辑」** 两种模式，可在同一程序里切换。
- 词库组合沿用左浏览、右组合的布局：左侧筛选词条，右侧按分类槽位整理已选提示词。
- 分类编辑用于维护本地分类库；编辑保存后，词库侧会在需要时刷新数据。

### 提示词预设管理

- 在词库组合右侧点击 **「提示词预设管理」**，可保存常用提示词组合。
- 支持类型：**角色设计**、**场景设计**、**服装设计**、**动作组**、**表情**、**自由组合**。
- 可为预设填写名称、设计备注，并执行 **「另存为新预设」**、**「覆盖并升版」**、**「载入到组合」**、**「删除」**。
- 覆盖升版会保留最近版本历史，方便回看此前修订。

### 预设配图

- 在预设管理中点击 **「导入配图」**，可为当前预设或草稿加入参考图。
- 配图以原文件保存在程序旁的 `runtime/preset-images` 目录；预设记录只保存本地路径，不再把图片塞进浏览器本地存储。
- 单预设最多 48 张；单张上限约 20MB，支持 jpeg / png / webp / gif。
- 悬停缩略图可查看本地路径；点击缩略图上的 **「×」** 可移除配图并删除对应文件。

## 交互与体验改进

- 回补一级分类颜色：主分类、子分类树、词条列表和右侧组合槽位会按分类显示对应色点与底色，便于快速辨认。
- 当前分类包括视觉、镜头、人物、外貌、服饰、动作、表情、场景、物件、图形、引用、成人、猎奇、负面、角色与画师等。
- 单顶栏模式切换条改为安静样式，减少与词库页重复的视觉干扰。
- 程序包、文件夹与 exe 均带版本号，便于区分分发与回滚。

## 问题修复

- 修复封装后仍会打开外部浏览器页面的问题；现在只在程序自带窗口内使用。
- 修复分类 ID 与颜色规则不一致导致主分类、下级分类和词条全部发灰的问题；现在各级筛选与词条都会正确上色。
- 修复预设配图用 base64 塞进本地存储、被迫限制分辨率与张数的问题；现在改为本地文件路径存储。

## 使用方法

### 启动程序

1. 打开文件夹 **`dist\TagToolbox-1.0.0\`**。
2. 双击 **`TagToolbox-1.0.0.exe`**。
3. 等待本地服务与窗口启动完成后，即可在窗口内操作。
4. 使用完毕后直接关闭窗口退出。

### 词库组合

1. 确认顶部模式为 **「词库组合」**。
2. 在左侧选择主分类、子分类，或使用搜索筛选词条。
3. 点击词条加入右侧对应槽位；也可在右侧拖动调整位置。
4. 在底部导出区选择 **「英文串」**、**「中文串」**、**「中英对照」**、**「负向串」** 或 **「画师串」**，再点击复制。

### 提示词预设

1. 在右侧点击 **「提示词预设管理」**。
2. 选择预设类型，填写名称和可选备注。
3. 如需参考图，点击 **「导入配图」** 选择图片。
4. 点击 **「另存为新预设」** 保存；之后可 **「载入到组合」** 一键恢复，或 **「覆盖并升版」** 更新现有预设。

### 分类编辑

1. 切换到顶部 **「分类编辑」**。
2. 在编辑器中调整分类树与词条归属。
3. 保存后返回 **「词库组合」**；若本次有改库，词库会重新读取最新数据。

## 兼容性说明

- 本版本为桌面程序首发包，分发时请拷贝整个 **`TagToolbox-1.0.0`** 文件夹，不要只拷贝单个 exe。
- 提示词预设仍保存在本机浏览器存储键中；同一台电脑、同一用户配置下可继续使用已有预设名称与词条组合。
- 旧版若曾用 base64 保存配图，仍可显示；新导入的配图只会写入 `runtime/preset-images`。
- 运行时数据库位于 `runtime/classification_editor.sqlite`。首次启动会从 `db` 目录复制源库；已有 runtime 库不会被自动覆盖。
- 当前打包源库为可恢复的 r162 检查点版本。若你本地另有更新的分类库，可自行替换 `db/classification_editor_source.sqlite`，并删除或备份旧的 `runtime/classification_editor.sqlite` 后再启动。

## 已知问题与待验证

- **已知问题：** 更早的 V8 冻结库 r181 在迁移过程中未能完整保留进本程序包；当前默认源库为 r162。若你仍持有 r181 备份，可按上一节方式手动替换。
- **待验证：** 不同 Windows 机器上 WebView2 运行时缺失时的首次安装体验；若窗口无法打开，请先安装 Microsoft Edge WebView2 运行时后再试。
- **待验证：** 提示词预设浮窗的自由拖动与对角缩放，尚未作为本版正式能力交付。
